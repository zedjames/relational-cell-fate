# Provenance policy

Raw third-party datasets are not automatically mirrored in this repository.

For each source, the release records:

1. publication and accession;
2. exact public source location or upstream repository;
3. frozen upstream code commit where applicable;
4. acquisition date in the final release manifest;
5. hashes for downloaded or derived files used in the paper;
6. deterministic preprocessing / reconstruction instructions.

Paper-specific derived artifacts may be distributed when doing so is compatible with the source authority and licensing terms.
