# Public release boundary

This repository exists to reproduce and inspect the empirical results reported in the accompanying paper.

## Included

- public-source provenance and accession metadata;
- paper-specific finite carrier / state / future artifacts where redistribution is appropriate;
- registered empirical result tables and control outputs;
- scripts needed to recompute the manuscript's reported statistics and figures;
- hashes and validation receipts for the frozen release;
- minimal verification metadata tying manuscript claims to checked release artifacts.

## Not included

- the private development repository;
- the broader tiered formal environment;
- generic or reusable implementation of the relational calculus;
- unrelated theorem libraries or research programs;
- research-generation, orchestration, or exploratory machinery;
- private development history not required to reproduce the manuscript.

The release target is reproducibility of the published computation, not reconstruction of the private research environment.
